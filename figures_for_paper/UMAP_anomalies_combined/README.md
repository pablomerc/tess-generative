# Combined UMAP + anomaly-detection figure (paper)

Single PDF combining the two paper figures vertically:

- **Top band** — 1×3 UMAP scatter panels:
  `Physics latent (ours)` | `Instrument latent (ours)` | `AION latent`.
  All three share the same 4096 anchor galaxies and the same 20 highlighted
  pair markers (color × shape combinations). UMAPs forced square via
  `ax.set_box_aspect(1.0)`.
- **Bottom band** — 1×3 stamp groups (same column order as the UMAPs):
  the top-12 deduplicated normalizing-flow HSC anomalies for each encoder,
  rank-labelled `#1`–`#12`. AION is on the right to mirror the UMAP
  arrangement (i.e. swapped vs. the standalone `anomaly_detection_figure/`).

## Files

```
UMAP_anomalies_combined/
├── README.md                            # this file
├── make_figure.py                       # render figure from _cache/
├── combined_umap_anomaly_science.{png,pdf}   # the figure (SciencePlots styling)
└── _cache/                              # all inputs — fully local, no upstream paths
    ├── ours_umap_base_n4096_s314.npz             # UMAP coords for Physics + Instrument
    │   keys: hsc_umap_1, legacy_umap_1, hsc_umap_2, legacy_umap_2, selected_indices
    ├── ours_umap_base_n4096_s314_metadata.json   # provenance
    ├── aion_umap_neighbors_efficient_n4096.npz   # UMAP coords for AION (same 4096 anchors)
    │   keys: hsc_umap, legacy_umap, anchor_row_idx
    ├── aion_umap_neighbors_efficient_n4096_metadata.json
    ├── anomaly_ours_physics_top12.npz            # HSC anomaly stamps from physics encoder
    ├── anomaly_ours_instrument_top12.npz         # HSC anomaly stamps from instrument encoder
    └── anomaly_aion_top12.npz                    # HSC anomaly stamps from AION
```

Each `anomaly_*_top12.npz` carries `top_raw int64[12]`, `top_pcts float[12]`,
`hsc_imgs float[12, 5, 160, 160]` (g/r/i/z/y stamps), and provenance fields.

## How to reproduce

```bash
python make_figure.py
```

Re-renders both PNG and PDF. Reads only `_cache/`. No upstream HDF5 or
checkpoint access required.

## Provenance

- The UMAP coords were generated by:
  `galaxy_images/galaxy_model/visualization_scripts/regenerate_umap_base.py`
  (ours, base ckpt step=87000, seed=314, 4096 anchors from
  `data/neighbors_efficient/`) and
  `galaxy_images/galaxy_model/aion_benchmark/aion_umap/aion_umap_neighbors_efficient.py`
  (AION-base, no token cap, mean-pool over tokens, same 4096 anchors).
- The anomaly caches are byte-for-byte copies of
  `figures_for_paper/anomaly_detection_figure/_cache/*.npz`, renamed for
  clarity. See `figures_for_paper/anomaly_detection_figure/README.md` for the
  full anomaly-detection pipeline (367k HSC pool, NLL → top-12 with 10″
  sky-position deduplication).
